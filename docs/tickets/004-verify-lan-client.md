# 004：验证局域网客户端、流式调用与故障切换

- **状态：** `ready-for-agent`
- **依赖：** 003 统一 Token 与本机最小调用已通过
- **后续解锁：** 005 备份与回滚
- **执行角色：** 独立验证窗口；修本人在受信任设备上完成实际客户端操作

## 目标

确认自有局域网设备可以通过统一 New API 入口调用已验证模型别名，并验证网络暴露、普通请求、流式响应、错误分类和受控主备切换符合项目边界。

## 允许修改范围

- API Hub 专属 Windows 防火墙规则与 New API 后台的渠道启停/优先级设置。
- 修本人控制的受信任局域网客户端的统一入口配置。
- 项目 Vault 中脱敏后的验证证据、截图说明和票据状态。

## 禁止修改范围

- 不配置路由器端口转发、公网 DNS、公共代理、Tailscale 或 ZeroTier。
- 不在访客 Wi-Fi、公共网络或未知设备上验证。
- 不将 Token、上游 Key、完整请求认证头或敏感响应写入报告。
- 不删除主渠道、持久化数据或容器来模拟故障。
- 不在流式响应已开始后自动完整重放请求。

## 前置核实

1. Windows 主机和测试设备处在同一受信任私有局域网或被明确批准的可信子网。
2. 记录 Windows 局域网 IP、端口、客户端设备类型和测试时间；不记录 Token。
3. 检查 Windows 网络配置为私有网络；确认防火墙规则最小化且仅覆盖所需端口、协议和网络范围。
4. 确认目标客户端配置为统一入口，而非直接上游 URL。
5. 确认有一个已验证的主渠道，必要时另有能力等价的备用渠道。

## 实施步骤

1. 在另一台自有局域网设备上访问管理后台登录页或受控健康检查，确认网络可达；管理后台凭据不得共享给非管理员客户端。
2. 在该设备的调用客户端中设置统一 Base URL、New API Token 与 `chat-general`。
3. 发起最小非流式对话请求，记录请求成功、模型别名和脱敏渠道代号或可验证路由结果。
4. 对已在 002 声明支持的能力逐项发起低风险真实请求：文本流式、`tools`/`tool_choice`/`tool_calls`、流式工具调用增量、图片内容块、`reasoning_effort` 或等效推理控制、以及独立 `/v1/embeddings`。记录成功、失败或未支持的结论，不保存 Token、认证头或敏感内容。
5. 使用不存在的统一模型名或明确不兼容的参数进行受控错误测试，确认错误清晰返回，且没有无限重试或悄悄切换到不等价模型。
6. 受控故障切换测试：
   - 保留主渠道配置和数据。
   - 通过后台临时禁用主渠道或采用可恢复的优先级调整，制造可恢复路径。
   - 对每一个具备能力兼容备用渠道的公开路由，分别验证文本、流式、工具、视觉、推理或 Embedding 的接管边界。
   - 不对已经开始工具执行或已经输出流式内容的请求重放完整请求；不同向量空间的 Embedding 不做接管。
   - 验证备用渠道接管后恢复主渠道，并重新确认主路径。
7. 如渠道支持，观察 `429`、超时或预期 `5xx` 时的行为；没有可靠、安全的测试条件时，记录为“未演练”，不得虚构通过。
8. 检查防火墙和服务未被意外暴露到公共网络。若设备离开受信任局域网，调用应无法访问或不被允许。

## 验收标准

1. 至少一台其他自有局域网设备可通过 `http://<Windows-LAN-IP>:3000/v1` 或执行时批准的明确等效地址完成普通对话。
2. 客户端仅保存统一入口、New API Token 和统一模型名。
3. 002 中每个声明支持的流式、工具、视觉、推理和 Embedding 能力均在真实客户端路径上得到通过、未支持或失败的明确结论；不支持不会被伪装为网关禁用。
4. 非法模型、鉴权失败或参数不兼容返回明确错误，不无限重试，不假装成功。
5. 主渠道受控不可用时，能力契约兼容备用渠道仅在可重试策略下接管；恢复后主渠道再次可用。
6. 服务未配置为公网、端口转发或访客网络可用服务。
7. 验证记录中没有密钥、Token、认证头、完整敏感日志或用户请求内容。

## 失败处理与回滚

- LAN 不可达：先核对 Windows 私有网络、防火墙范围、IP 变化和端口监听；不通过关闭所有防火墙或改为公网暴露解决。
- 客户端认证失败：核对 Token 状态和统一 Base URL，不回显 Token。
- 流式失败：标记该渠道流式未验证或不支持；普通对话正常不等于流式自动通过。
- 主备切换不正确：恢复原始优先级/启用状态，停止对外使用该别名，重新检查能力与重试策略。
- 发现过宽网络暴露：立即收紧规则、停止服务或限制监听范围，并重新验证。
